# Specification

## Summary
**Goal:** Remove pricing tiers and price displays from the site while keeping /pricing as a valid non-pricing route that directs users to request a quote via Contact.

**Planned changes:**
- Remove Pricing page content that shows any pricing tiers, package cards, currency amounts, or price-related sections across the website.
- Update the main navigation (desktop and mobile) to remove the “Pricing” link.
- Update the footer “Quick Links” to remove the “Pricing” link.
- Convert the /pricing route into a non-pricing page with English copy stating pricing is available upon request and a clear CTA linking to /contact.

**User-visible outcome:** The site no longer displays pricing information or links to a pricing page, and users who visit /pricing are guided to request a quote via the Contact page.
